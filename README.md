# job-search

一个用于求职岗位筛选的 **Trae 技能（Skill）**：上传简历并给出招聘网址与心仪岗位类型后，自动解析简历生成候选人画像，抓取招聘网站上的岗位并逐条阅读 JD，最后按**简历匹配度**和**投递成功率**对岗位综合排序，辅助决定投递优先级。

## 它能做什么

1. **解析简历**：支持 Word（.docx）和 PDF（.pdf），自动生成结构化的候选人画像（Markdown）。
2. **抓取岗位**：给出招聘网站链接后，自动翻页抓取全部岗位，逐个阅读岗位 JD 全文（而不是只看岗位名）。
3. **综合排序**：先核对学历、毕业届次、外语、经验等硬门槛，再按匹配度与成功率给出 0–100 分的排序、Top 推荐、保底岗和慎投岗。
4. **可复算**：抓取数据与评分脚本保存在本地工作区，结论可随时复查。

适用对象：正在找实习或校招/社招岗位、希望按个人简历客观评估"哪些岗位值得投"的求职者。

## 使用流程

在对话中按下面方式操作即可：

1. 把简历文件（Word/PDF）发给助手；
2. 告诉助手**招聘网址**和**心仪的岗位类型**（可多个，例如：产品经理 / 软件交付经理 / 数据分析）；
3. 等待助手抓取岗位并输出综合排序结果。

如果只说了找工作但还没发简历，助手会先提示你发送简历与招聘信息。

## 安装方法

1. 在本仓库页面点击绿色的 **Code → Download ZIP**，解压；
2. 把解压出的 **`job-search` 整个文件夹**复制到你 Trae 项目的技能目录下：

```
你的项目文件夹/
└── .trae/
    └── skills/
        └── job-search/
            ├── SKILL.md
            ├── references/
            └── scripts/
```

   （若没有 `.trae/skills/` 目录，手动新建即可。）
3. 重新打开该项目，技能会被自动识别，之后直接在对话中发送简历即可使用。

## 环境要求

- 支持 Agent Skills（SKILL.md）规范的 AI 工具，例如 [Trae](https://www.trae.cn/)（放入项目的 `.trae/skills/` 目录，即上文安装路径）。
- Python 3
- 首次使用前安装依赖（requests 用于抓取岗位，pypdf 用于解析 PDF 简历）：

```bash
pip install requests pypdf
```

Word（.docx）解析无需安装任何第三方库。旧版 `.doc` 格式请先用 Word 另存为 `.docx` 或 `.pdf`。

## 目录结构

```
job-search/
├── SKILL.md                      技能主文件（完整流程与评分规则）
├── references/
│   └── profile-template.md       候选人画像模板
└── scripts/
    ├── extract_resume.py         简历文本抽取（docx / pdf）
    └── fetch_template.py         招聘站点抓取脚本骨架
```

## 说明

- 简历和分析结果只保存在你**本地工作区**，不会上传到任何第三方。
- 画像与评分严格基于简历中写明的事实，不会虚构经历或技能。
- 招聘网站结构可能随官网更新而变化，个别站点可能需要重新适配抓取方式。
